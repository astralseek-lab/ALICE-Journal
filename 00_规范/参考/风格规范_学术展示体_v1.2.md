## 一、结构（开门见山，六节固定；DOM 顺序即阅读顺序）

**不写导语/背景节**；痛点句并入摘要开头；意义不收正文节、归摘要。

1. **核心亮点**（`<blockquote>`，abstract 定位）：痛点句 + 总结句 + 4–6 条加粗要点——**全文全局内容尽收于此**（数据/模型/结果/结论 + 意义要点）；
2. **图**（直出）：摘要后第一张图紧跟核心亮点，**开门见山、无需引用句**（v0.11 起；`build_html.py` 未引用图自动落位于核心亮点 blockquote 之后）；caption 随图下（管线自动），图源与许可齐全；
3. **文字解释**：跟随图后，只写方法学与结果两块，文字充当图表阐述；多图单元按「图 2→文字 2」依次推进，图 N 全文恰一处引用句，图随句插入；
4. **亲手验一验**：编号声明清单 + 加粗的复现文件路径与复现说明书行（真实可点链接）；
5. **免责**（v0.11 起**无节标题**，一段斜体紧随验证块）：两层固定句式（见文头免责裁定）；
6. **引用**：文末 `<blockquote>`，一条横线排到底。

> 图注节（`## 图注`）在 article.txt 中仅作 caption 源，不渲染为独立节；「方法学与结果」不设节标题（2026-11-03 用户终审裁定，v0.9 起）。

## 二、核心亮点（摘要 = 全局内容）

- **开头两句定式**：先痛点（读者熟悉的困境，一两句）后总结（本篇最硬的数字对比 + 论断）。痛点句与总结句合计 ≤80 中字（速读口径）。
- **要点 4–6 条，必含「数据」类**；按 数据/模型/结果/结论 标签加粗领起，一条一个论断；**「意义」以一条要点呈现**（对使用者/研究者的行动建议浓缩为一句论断，不写分条展开、不收开放式问句）。
- **数字优先**：每条以关键数字为骨架，定性描述服从数字；数字可后随一个括号注（拆分口径、对比基线）。
- **总量闸门（v1.2 口径）**：**中文 ≤300 字为硬上限**（用户裁定「300 字」口径）；总字数 ≤600、总非空白字符 ≤600 为辅助闸（顶层 v5.9.4 附录 B；`format_and_qc.py` 按总字符验，`qc_report_final.py` 按中文字数验）。润色时先量后改，超了先砍形容词，不砍数字。
- 不写「一句话速读：」等前缀标签。

## 三、正文（文字解释，只展示图表内容）

- **只写两块**：方法学（对象如何定义、数据如何产生、模型如何构建）与结果（治理/实验期内发生了什么，数字说话）；综述性背景、历史沿革一律不写；**意义、展望、行动建议一律不写**（已归摘要）。
- **图先于文**：图在摘要后直出，解释文字跟随其后；每个图 N 在正文恰出现一次（引用句），位置在与之最相关的段落之末；`build_html.py` 会按此句把图插在其后（首图引用句紧跟核心亮点，实现「摘要→图→文」）。文字是图的阐述，不是图的重复。
- 段落以 `**方法学：**`/`**结果：**` 加粗领起，一段一事；句间用分号组织并列数字。
- 量级参考：正文两段合计 ≤400 中字（摘要既管全局，正文只留图表阐述）。

## 四、语言（学术期刊 register）

1. **精确克制**：论断式短句；不用口语钩子（「心里直打鼓」类）、不用网络语；保留论文原意的凝练短语可用（如「宁减勿滥」），但须有数字或引文支撑。
2. **术语纪律**：专名首次出现给全称+缩写（Gene Ontology, GO）；之后统一用缩写。release、版本号、库名原样保留。
3. **数字格式**：千分位（1,135,364）；百分比与计数不混用（「84% 人类基因」）；区间用 en dash（35%–78%）。
4. **衔接**：痛点—方法—结果之间不用过渡寒暄；每节第一句直接给信息；全文保持严肃科研期刊语域（2026-11-03 定位裁定）。

## 五、亲手验一验（验证块）

- 声明逐条编号，一条一个 claim：结论 + 关键数字 + 口径注（样本量、证据码、复算差异及原因）。
- 复算与论文不一致时，写明差异与口径原因，**判语用「不构成论文错误」，不写贬义词**。
- 「复现文件路径」与「复现说明书」两行**加粗**，真实可点链接（`<a href>`），并与上下行各自独立成段（空行分隔；管线按空行分段，段内换行会并流）。
- 只写 verified 声明的概括；可复验/未达边界声明一句带过（「另有 N 条……」），状态明细指向单元声明清单。

## 六、免责声明与固定块

- 免责只写两层，固定句式须含「不构成对其科学性的认可」（v1.2 起；旧句「不构成对论文科学结论的认可」废止）；全段斜体（管线中以字面 `<em>` 实现，markdown 星号不转换）。
- 已废止句（「本文不构成医疗建议。」「校验通过 ≠ 结论正确。」）**不得写入**，QA 会主动判负。
- 图注、引用为冻结块：图源含期刊年卷页 + DOI + 许可；引用含更正信息（如有）、数据来源 release、单元编号、署名单位。

## 七、排版管线约定（article.txt 侧）

- 空行分段；每行要独立呈现就给空行。
- 加粗用 `**`；斜体与 blockquote 用字面 HTML（`<em>`、`<blockquote>`）；外链用字面 `<a href>`。
- 「引用」是裸行（无 `##`）；图注节标题为 `## 图注`，条目 `Figure N | caption`（仅作 caption 源）。
- 文件信息行紧跟标题行：`<!-- 文件信息：期刊名 IF=x.x -->`；标题已含《期刊名》时文件名后缀只留 IF 段（脚本自动去重）。
- Windows 文件名非法字符由 `build_html.py` 全角化，仅影响文件名。

## 八、数字与事实纪律

- 摘要、正文、验证块中的同一数字必须一致；任何润色不得改动数字、日期、版本号。
- 摘要与正文允许重复关键数字（摘要管全局、正文管图表阐述），但口径注只写一处。
- 不代写事实：缺数据就报缺，不为凑检查项编内容（顶层 §0.5 硬约束，本规范不豁免）。
